# Machine Doctor AI

공작기계에서 발생하는 이상 현상과 발생 조건을 입력하면 AI가 예상 원인, 점검 항목, 권장 조치 및 안전 주의사항을 안내하는 웹 프로젝트입니다.

## 주요 기능

- 이상 현상 및 발생 조건 입력
- OpenAI API 기반 설비 상태 분석
- 예상 원인, 점검 항목, 권장 조치 제공
- 입력값 누락 및 서버 오류 안내
- 모바일 환경을 고려한 반응형 화면

## 프로젝트 구조

```text
A1-3/
```

## 설치 방법

터미널에서 프로젝트 폴더로 이동한 후 아래 명령어를 실행합니다.

```powershell
pip install -r requirements.txt
```

## API 키 설정

프로젝트 최상위 폴더에 `.env` 파일을 만들고 아래와 같이 작성합니다.

```text
OPENAI_API_KEY=본인의_OpenAI_API_키
```

API 키는 절대로 GitHub나 공개 문서에 올리지 않습니다.

## 서버 실행

```powershell
python api/analyze.py
```

아래 문구가 나타나면 서버가 정상 실행된 것입니다.

```text
Running on http://127.0.0.1:5000
```

서버 실행 중에는 터미널을 닫지 않습니다.

## 사용 방법

1. 웹페이지를 엽니다.
2. 이상 현상과 발생 조건을 입력합니다.
3. `AI 분석하기` 버튼을 누릅니다.
4. AI 분석 결과를 확인합니다.

## 예시 입력

```text
이상 현상: 주축 8000rpm 이상에서 고주파 소음이 발생합니다.
발생 조건: 고속 회전 시 진동과 온도가 함께 증가합니다.
```

## 주의사항

이 프로젝트의 분석 결과는 참고용입니다. 실제 설비 점검 및 수리는 반드시 안전 절차를 준수하고, 필요한 경우 전문가의 진단을 받아야 합니다.
